# Testing

The suite uses FiveAM. [Runnable examples](examples.md#run-without-downloads) have an offline smoke-test system.

```sh
sbcl --non-interactive --eval '(require :asdf)' --eval '(asdf:test-system :cl-inference)'        # client
sbcl --non-interactive --eval '(require :asdf)' --eval '(asdf:test-system :cl-inference/local)'  # engine
```

`asdf:test-system` signals an error if any check fails. From a REPL, `(cl-inference/tests:run-tests)` and `(cl-inference/local/tests:run-tests)` return true when every check passes.

The [client](client.md) suite loads neither the engine nor cl-tensor and passes on SBCL, CCL and ECL. The CPU local fixture suite passes on all three, including GGUF tensor loading, tiny-model completions and the seeded sampler golden sequence. Real-model CPU acceptance is verified on SBCL.

Live Ollama tests are skipped unless `CL_INFERENCE_OLLAMA_URL` (the `/v1` route) or `CL_INFERENCE_OLLAMA_NATIVE_URL` is set; `CL_INFERENCE_OLLAMA_MODEL` picks the model.

Full-model checks compare against a dev-only reference kept in the gitignored `reference/` directory, which also holds llama.cpp's `ggml-vocab-llama-bpe` and `ggml-vocab-qwen2` fixtures for the tokenizer. `reference/chat-templates.py` needs `jinja2` and the two official templates in `reference/templates/`; it regenerates the chat template expectations.

[Half-precision measurements](half-linear-performance.md) benchmark complete `linear` calls, including conversion, result allocation and tensor metadata. Performance measurements run separately from test suites to avoid contention.

## MLX

After building cl-mlx, `asdf:test-system "cl-inference/mlx"` runs native model, client and acceptance-harness fixtures. `asdf:test-system "cl-inference/mlx/acceptance"` compares real Llama and Qwen models with a pinned Python MLX oracle. Set `CL_INFERENCE_MLX_ACCEPTANCE_STRICT=1` to require every reference input and case; absent inputs skip in ordinary runs, while hash mismatches fail. See [MLX acceptance](mlx-acceptance.md) for setup and numerical bounds.

## Acceptance

`cl-inference/local/acceptance` checks Llama 3.2 1B Instruct and Qwen3 0.6B in F16 and Q8_0 against a pinned llama.cpp reference. It compares metadata, prompt ids, layer outputs, final logits and greedy generation.

Models and oracle dumps stay in gitignored `reference/`. Missing inputs skip individual cases; skips do not establish acceptance. See [Model acceptance](acceptance.md) for downloads, commands and numerical bounds.

Q4_0, Q4_K_M and Q6_K real-model cases use a F32-dequantized reference. See [Q4/Q6 acceptance](quant-acceptance.md) for reproducible preparation and strict verification.
