# cl-inference

> **Work in progress.** This project is under development; expect missing features and breaking changes.

Extensible LLM inference for Common Lisp, built on [cl-tensor](https://git.sr.ht/~takeiteasy/cl-tensor). Model architectures are declared in a Lisp DSL; a similar architecture inherits from an existing one and overrides what differs.
